# FLIGHT-PLANNER

Repository package for the Thailand flight-planning web app.

## Included

```text
planner.html
.github/
  workflows/
    update-aip-thailand.yml
scripts/
  update_aip_thailand.py
README.md
README-AIP-AUTO-UPDATE.md
```

## GitHub Pages

Use `planner.html` at the repository root.

If your existing `flight` repository already contains these runtime files/folders,
keep them in place because the current app can reference them:

```text
manifest.webmanifest
sw.js
map/
  thailand.pmtiles
  elevation.pmtiles
```

They are not regenerated by this package.

## Automatic Thailand AIP update

Workflow:

```text
.github/workflows/update-aip-thailand.yml
```

Schedule:

- Every Monday at 18:00 Thailand time
- GitHub Actions cron: `0 11 * * 1`
- Manual run is also available from the Actions tab.

The updater does not use Claude, OpenAI, or another AI service.

It checks CAAT Published eAIPs, selects the **Currently Effective Issue**, downloads
the configured AIP source pages and stores them under:

```text
data/aip-thailand/current/
```

The workflow commits only when the downloaded AIP snapshot changes.

## Required repository setting

Open:

`Settings → Actions → General → Workflow permissions`

Select:

`Read and write permissions`

This allows `github-actions[bot]` to commit updated AIP files back to the repository.

## Important

The current updater automatically downloads the authoritative AIP source snapshot.
It does **not yet** rewrite the embedded airport/ENR/airspace JavaScript arrays
inside `planner.html`. A deterministic parser can be added to the workflow next if
you want the live Flight Planner layers themselves to update automatically.
